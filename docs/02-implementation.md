# 0.1 Preview 实现与验证

2026-10-29。此版本为可体验的第一版，尚未完成全部正式版验收。

## 界面与平台

单窗口中将目标和主操作置顶；近期丢包、窗口 RTT、jitter 与样本数居中；三图共享时间范围和悬停时间，历史浏览独立于采集；日志操作与原始记录放下方。缺失值不画成零，曲线不跨缺失窗口连接。实际截图见 [README](../README.md)。

当前仅支持 macOS 14+，采用 SwiftUI + Charts，按本机架构构建。Windows、Android、iOS 属于未来可能扩展的平台，尚无支持时间承诺。

## 采集与统计

每秒独立调用系统 `/sbin/ping -n -c 1 -W 1000 -t 2 <target>`，目标以独立参数传入，禁止 shell 拼接。固定五秒窗口按请求启动的单调时间划分，保留 UTC 墙钟；每个请求另设四秒进程看门狗。进程与可能的 DNS 开销会影响实际发包间隔，请求启动时刻并非内核实际发包时刻。

顶部丢包率使用最近 60 秒（12 个五秒窗口）的合计丢失数 / 合计有效探测数，不平均各窗百分比。实时排除尚未结束或有在途请求的窗口，可能滞后一个窗口及等待时间。启动不足一分钟时显示实际覆盖秒数；暂停后纳入已完成请求形成的 partial 尾窗。无有效探测显示缺失。

冻结跟随或离线回放时，卡片显示“浏览位置前 60 秒”，以可视范围右边界向下对齐五秒窗口。累计丢包率保留在会话概览；曲线为逐五秒窗口。

界面将 RTT 命名为“平均往返时延（RTT）”，数值不除以二。jitter 为同窗相邻成功序号 RTT 差绝对值的平均值，遇丢包、采集空档或窗口边界断开。

## 日志与回放

每次会话创建独立 `session.csv` 与 `diagnostics.txt`，暂停/继续沿用当前文件。CSV 保存元信息、窗口指标、样本数及状态；诊断文本保存事件、逐包结果与原始输出。不再生成 JSON，兼容早期 JSONL 只读导入。

CSV 窗口终了且在途请求结束后写入；暂停和导出保存已完成的尾窗。同窗恢复时原位更新最后一行，避免重复窗口。数值最多保留六位小数，回放统计与实时值的允许差为 0.000001 ms 或百分点。导出完整会话目录；不自动删除日志。

CSV 回放使用窗口汇总模型，不生成虚假的逐包记录；原始输出从配套诊断文件查看。格式和限制见 [CSV 日志规范](03-csv-log-format.md)。

## 退出

关闭最后一个窗口时退出应用，由 NSApplicationDelegate 管理。退出先停止定时器，等待在途 Ping 回调（最长约 4.5 秒），再写入尾窗与 session_end，关闭文件句柄。Cmd+Q 使用相同流程。超时仍未结束的请求取消，不伪造结果。

## 已验证

- 原生应用构建、启动和实际界面检查。
- 本机 loopback 以及 `1.1.1.1` 短时探测，三项曲线更新、实际 IP、暂停与历史保留；公网截图不代表长期质量。
- UI 实测点击 X 后进程退出。
- 核心测试：回复与超时解析、DNS 失败、jitter、丢包断开配对、全丢包缺失值、近期丢包加权/边界/错误排除/启动期。
- CSV 测试：元信息、空值、CRLF、重复与损坏行。
- 会话测试：真实系统 Ping、自动日志、CSV 回放一致性、partial 尾行更新、新目标新文件、无效文件拒绝、退出保存在途结果并关闭句柄。

复现命令：`./scripts/test.sh`。测试夹具位于 `/private/tmp/NetPulse-test-<uuid>/`，不进入仓库。
