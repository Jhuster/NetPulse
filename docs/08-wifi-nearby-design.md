# 周边 Wi-Fi 与连接变化：实现设计

日期：2026-10-30。本轮接续 [本机网络设计](07-local-network-design.md)，在当前连接信息之外增加周边扫描与连接变化记录。

## 展示与统计边界

- 用户点击后才扫描，按 2.4 / 5 / 6 GHz 分开查看；支持名称/BSSID 搜索，默认展示当前 Wi-Fi 频段。列表包含名称、BSSID、主信道、带宽、RSSI、安全模式，悬停显示噪声和 SNR。
- 每点表示一条扫描记录的主信道和 RSSI，点击列表行可定位。蓝色标记仅在当前 BSSID 与扫描结果一致、扫描接口与当前 Wi-Fi 接口一致且快照未过期时显示；不凭同名 SSID 猜测当前 AP。
- 主信道与带宽并不足以在所有制式下恢复宽信道中心和实际覆盖范围。因此本轮交付 **主信道分布**，不绘制未经验证的宽信道占用轮廓。相同/相邻主信道只提示可能重叠，不等于测得干扰或空口拥塞，不自动推荐最佳信道。
- 扫描记录可能因隐藏网络、系统合并、权限或未回复少于实际 AP 数量。无结果不证明没有网络；名称缺失显示不可用，不直接断定是隐藏 SSID。最多保留 512 条按 RSSI 排序后的记录。

## 系统 API、权限与异步状态

使用公开的 [CoreWLAN scanForNetworks](https://developer.apple.com/documentation/corewlan/cwinterface/scanfornetworks%28withssid%3Aincludehidden%3A%29)，`withSSID: nil, includeHidden: false`，不定向寻找某个隐藏 SSID、不连接/切换网络、不上传结果。当前 Xcode SDK 的 `CWInterface.h` 明确说明扫描调用会阻塞、BSSID 受定位授权控制。

应用先检查定位授权；由用户点击授权入口后才能扫描，不自动弹窗。扫描在 utility 任务进行，不阻塞界面，可能短时影响无线时延。扫描期间暂停本地 CoreWLAN 轮询，结束后刷新，避免并发读取产生不完整连接快照；时间空档按现有趋势规则断线。

系统没有为该公开同步 API 提供取消句柄，因此 UI 使用“结束等待”，不声称取消系统扫描。等待预算 20 秒，超时/结束等待后不应用迟到结果；在原调用结束前禁止重复扫描，避免堆积后台任务。系统路径、观察到的本机配置或权限变化会使旧结果过期，并阻止旧请求覆盖当前视图。失败保留旧快照，但明确其状态与时间。

## 连接变化记录

按本机快照约每 2 秒观察，保留最多 200 条，页面显示最近 20 条。包括观测基线、接口/连接状态、网络名称、BSSID、信道及标识可读性变化。

- 前后均有 BSSID 才比较接入点；同名 SSID 的 BSSID 变化记录为“同名网络的接入点变化”。这可辅助排查疑似漫游，但不等于已测量切换耗时、丢包或业务影响。
- 权限导致标识从缺失到可读或反向变化，单独记录可读性变化，不当成漫游。
- 初次进入、暂停/离开后恢复或超过 5 秒的采样空档重新建立基线；不推断空档期间发生的连接事件。更短的多次切换也可能被轮询漏掉。

## 导出

“导出快照”继续使用独立 `.netpulse` 目录，新增：

- `wifi-scan.csv`：仅在已有成功扫描时生成，包含扫描时间、接口、快照状态及逐记录字段；旧结果标为 stale。
- `wifi-events.csv`：当前保留的连接变化记录，明确来源是周期观察，不是逐帧漫游测量。

沿用缺失留空的约定，CSV 对逗号、引号转义；名称中的换行写成可见的 `\n` / `\r`，防止打乱一行一条记录的可读性。导出提示说明包含本机和周边网络标识；不自动写入磁盘或上传。

## 验证

- `WiFiDiagnosticsTests`：匹配与缺失、基线/接入点/权限可读性变化、暂停与保留上限、CSV 转义、权限门槛、重复点击、超时、结束等待、过期/迟到结果、失败、关闭 Wi-Fi 及导出。
- 已执行一次真实 CoreWLAN 扫描，本机返回 11 条记录；仅打印数量，不把真实 SSID/BSSID 写入仓库。
- `WiFiDiagnosticsPreview` 是可选的合成数据布局检查程序，不参与 release 构建；用于检查图表、频段筛选、缺失数据和 AP 表格，不作为真实测量证据。
- 尚未做各类无线网卡和系统版本覆盖、真实漫游性能验收、宽信道中心解析或空口利用率测量。
